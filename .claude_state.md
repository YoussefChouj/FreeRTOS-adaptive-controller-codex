### Mutation-testing gotcha that cost ~20 min
`io.open(P,"w").write(mutated)` **without an explicit `.close()`** can still be
unflushed when `subprocess.run(["node", …])` reads the file — the mutation
silently does not apply and the test passes, which reads exactly like a
toothless assertion. Always `f = io.open(...); f.write(...); f.close()`.
Also: reading a CRLF file in text mode and writing it back with `newline=""`
converts it to LF, so the file shows as modified afterwards with an empty
`git diff --stat`. `git checkout --` it.
