# R4 summary — RBF neural adaptive quadrotor control in practice & payloads

1. Bottom line: real RBF/adaptive flight under slung or asymmetric loads is thin and recent; most Chinese
   RBF-quadrotor papers are simulation-only, so vp16's flown rope-load-vs-PID demo is genuinely novel.
2. Chinese networks are tiny (5–10 hidden nodes), centres are small constants or a uniform grid, widths equal
   or nearest-neighbour-scaled; input normalisation is conventional but under-documented.
3. The one fully-flown embedded RBF (SANM, STM32H750/ArduPilot 400 Hz) uses per-axis 2-D slices (≈5 neurons),
   equal widths over [-10,10] rate error, no pitch×roll input, and needs no persistence of excitation.
4. Width = a×nearest-neighbour gap with a∈[1.0,1.5] is the standard taught value → vp16's "width=gap" rule is sound.
5. Cross-axis coupling is real and observable (RL paper captures roll/pitch moments of an on-arm 4–11% load)
   but SANM shows decoupling per axis suffices on hardware; vp16's 16 cross-Gaussians are more than the flown precedent.
6. Flown suspended/off-centre methods: energy-adaptive nonlinear (AAS 2018, vs LQR: max swing 0.199° vs 0.989°,
   ~5×), SANM RBF, RL recurrent-estimator (vs PID, ~4.6× lower error), RBF approximating CG-shift torque (AIAA 2025).
7. No published flown RBF-vs-PID number exists for a rope load; the AAS vs-LQR anti-swing gains are the realistic ceiling.
8. Embedded cost: 15 expf/cycle for 3×5-neuron nets ≈77% avg / 81% peak CPU, 255 kB RAM → vp16's 294 Gaussians/cycle
   needs a shared-width lookup table or expf-free kernel, not naive expf.
9. Failure modes found: high-frequency oscillation & unsafe on heavy asymmetric load for passive-robust policies (RL paper).
10. Parameter drift / need for PE near hover is fixed in flight by concurrent learning (Chowdhary, flown quadrotors,
    "weight error convergence without requiring persistency of excitation").
11. RBFNN-observer overshoot/oscillation under faults is reduced by updating centres AND weights (IET CTH2.70078, UNVERIFIED top confirmed report).
12. Residual error ball tracks per-axis learning rate (SANM: rates {35,35,10},{80,80,30},{120,120,50}) → gamma per axis, tuned per axis.
13. Plain PID under off-CG load develops a diverging static error → supports vp16's limited/projected bias-row static trim.
14. Top vp16 changes: confirm width multiplier a, keep cross-Gaussians low-gain, per-axis gamma, shared-width exp table, bias ≤15% projected trim.
15. UNVERIFIED this session: several Chinese node/centre values, Hassoun/Hindawi width numbers, IET and Robot 2019 quotes (sources blocked or binary).
