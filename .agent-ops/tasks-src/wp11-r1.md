  MRAC_ResetWeights(): the Theta/Whatf part of MRAC_Reset (:656-678) plus the xm/x_prev snap; no flag or simplex changes.
  MRAC_GateStep(), called first in MRAC_Control:
   1. fly_ticks: count up while armed && phase in {FLYING, LANDING} (saturate); reset to 0 otherwise, with
      hysteresis so a short phase flicker does not reset it (document the rule).
   2. learn_gate = armed && phase in {FLYING, LANDING} && fly_ticks >= MRAC_LEARN_HOLD_S / MRAC_DT.
      The same gate applies in shadow mode.
   3. Disarm edge, or phase LANDED / GROUND_IDLE: inj_alpha = 0 immediately, learn_gate = 0;
      on the disarm edge call MRAC_ResetWeights().
   4. Injection rising edge (output_injection_on 0->1): MRAC_ResetWeights(), ramp time restarts.
   5. inj_alpha while injecting and learn_gate open: smoothstep 3p^2-2p^3, p = t/MRAC_INJ_T_UP clamped to [0,1].
      If injection is on but the gate is closed (e.g. on at arm), alpha stays 0 and the ramp starts when the gate opens.
