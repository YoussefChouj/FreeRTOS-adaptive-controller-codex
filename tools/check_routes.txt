# Which check.sh steps a changed file requires. tools/check_routes.py reads this table; `bash tools/check.sh
# --changed` prints the union for the branch's diff. One row per line: <git pathspec-glob> <steps...>.
#
# Rules that keep this honest (tools/test_check_routes.py fails the gate when broken):
#   * Every step name must be one of check.sh's steps.
#   * Every top-level directory with tracked files needs a row, so a new tree cannot ship unrouted.
#   * A file matching no row runs doc-paths + doc-budget only. If you add a tree, add a row here first.
#   * a/** matches that directory and everything under it; * matches one segment; *.c matches that extension.
