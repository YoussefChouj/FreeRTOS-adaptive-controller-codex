## 2. Sparse Identification (SINDy)
SINDy uses data-driven sparse regression to find equations of motion. A simulated evaluation found that "only the Euler angles can be represented as Fourier basis functions, and the rest can be characterized by polynomials" [https://arxiv.org/abs/2305.16500]. Data derivatives were evaluated "using numerical approximation. Specifically, we used the finite difference method." [https://arxiv.org/abs/2305.16500]. Other research integrated SINDy with Proportional-Derivative (PD) approximations for DJI Matrice 100, though specific open-access flight log details remain scarce.

## 3. Feature Choice for Swinging Load via IMU Only
Accelerations and throttle are best. Research demonstrates that swing suppression can be achieved using "only the IMU (Inertial Measurement Unit) and throttle command already present on typical UAVs" [https://arxiv.org/abs/2608.18625]. The technique uses an EKF to estimate pendulum frequency, and "active damping controller adds a correction angle to the attitude loop" [https://arxiv.org/abs/2608.18625].

## 4. Phase Lag and Periodic Disturbances
To address phase lag on periodic disturbances, "composite adaptation" uses historical and current data. For instance, SSML-AC uses time consistency to "train the DNN to predict future disturbances from history" [https://arxiv.org/abs/2410.07575], addressing lags by forecasting the disturbance. Concurrent learning utilizes "concurrent learning-based mass estimation without persistent excitation" [https://arxiv.org/abs/2607.00024] to rapidly adapt to changes without lag.

## 5. Saturation and Hedging
Saturation causes instability in adaptive systems. A common technique is pseudo-control hedging (PCH), which modifies the reference model. However, recent RL techniques avoid this by mapping constraints directly: "torque tracking mitigates these issues by providing a more immediate and direct learning signal" preventing "saturated commands can overheat motors and cause hardware damage" [https://arxiv.org/abs/2409.12949].

## Implications for other variants
Structured S6/S10 features should include acceleration history for prediction-error adaptation, mitigating the 90-degree phase lag observed in vp13. L1 filtering (low-pass filter on adaptation) is critical; L1-NMPC demonstrates >90% error reduction, so applying L1 filters to the RBF grid outputs in future variants will ensure high-frequency stability while maintaining fast adaptation.
