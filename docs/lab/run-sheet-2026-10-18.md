## Branches & fallbacks

| Event | Do |
|---|---|
| flash exits non-zero | stop; no `--force` |
| ladder bench fails a plan | drop its `slow` groups, re-bench; no flight on an unmeasured plan |
| exp read-back refused (E1-E4) | not flashed, or 8081 not restarted |
| rung refused 0xEE | skip it |
| tilt or fence trip | that rung is today's limit |
| takeoff drift | `--gains c2` / `--post-takeoff-gains c3` |
| "NO FIX SENT" | land, check the tracker, re-fly |
| MULTI not merged or aborts | fly `lab_d_excite` (one axis) |
| TIC fails on an axis | keep the default model for that axis, fly it anyway in SHADOW only |
| att latch fires (A1-A12) | that kind/axis is done for today; note the latch code |
| airborne cap trips (120 s) | only expected if a hold > 120 s; check the script |
| I1 pack sags below 14.6 V mid-run | let it land; do not rerun on that pack |
