## Every boot (each new pack), before the first takeoff

| check / write | value |
|---|---|
| pack voltage | 16.8 V (gate lands at 14.3 V under load) |
| `kp_active` | reads 7 (wait for it, then do the writes below) |
| `g_land_gate_enable` | reads 3 |
| x/y MRAC on (until it is the boot default) | `g_ctrl_axis_mask = 63`, `mrac_flags.axis_enable_x = 1`, `mrac_flags.axis_enable_y = 1` |

Write the x/y values after `kp_active` reads 7: applying row 7 sets the mask back to 15 (4 axes).

## Per flight (on the ground, before `traj_go`)

`traj_p` is latched at `traj_go`, so set everything first. Defaults already right: path size 70 cm,
`move_s` 20, `yaw_follow` 1, `start_fixed` 1 (start at 0, 0, 0.85 m).

| what | PID | MRAC row NN |
|---|---|---|
| controller | `vp_id = 0`, ch8 off | `vp_id = NN`, ch8 on |
| path | `traj_id = 4`, `traj_p.f8_tilt_deg = 30` | same |
| stage 1, 4, 5 | `lim_mode = 0`, `traj_p.f8_laps = 2`, `traj_p.yaw_rate_dps = 90` | same |
| stage 2 | `lim_mode = 1`, `traj_p.f8_laps = 3`, `traj_p.yaw_rate_dps = 120` | same |
| stage 3 | `lim_mode = 2`, `traj_p.f8_laps = 4`, `traj_p.yaw_rate_dps = 160` | same |
| go | take off, hover, `traj_go = 1` | same |

## Watch during the flight

| variable | normal | act |
|---|---|---|
| `g_ctrl_axis_mask` (MRAC flights, before `traj_go`) | 63 | 15: x/y fell back off, rewrite the 3 x/y values |
| `traj_phase` | 4 (goto), 5 (settle), 1 (move), then return | stuck: `traj_stop = 1` |
| `lim_active` | equals `lim_mode` | not equal: land, rewrite |
| `g_land_gate_trip` | 0 | 1 = low voltage landed it: swap pack |
| `g_land_gate_sat_n`, `g_land_gate_sat_max_s` | 0 | write both down after landing |
| load swing | settles | grows over 3 swings: ch8 off (PID), land |

## Drone geometry (operator measured 2026-10-10)

| item | value |
|---|---|
| white guard | front-left motor, at +x, -y from the centre |
| guard diameter | 29 cm, centred on each motor |
| motor centre to motor centre | 27 cm adjacent, 38 cm diagonal |
| overall span | 57 cm side to side, 68 cm corner to corner |

Computed from these: arm 19 cm, motors at x, y = ±13.5 cm. 27 + 29 = 56 and 38 + 29 = 67 match the measured 57 and
68 within 1 cm. A 0.2 kg load under one motor gives 0.2 × 9.81 × 0.135 = 0.26 N·m on both pitch and roll.
Path at tilt 30 is x ±35, y ±61, z 0.50 to 1.20 m; with the 34 cm guard radius the drone sweeps about 1.4 × 1.9 m.
Lowest path point is 0.50 m, so keep sling plus load under about 0.4 m or the load reaches the floor (computed).

Still to measure: all-up mass with battery; which firmware motor number (mixer output) is the front-left one;
where the load hooks on (under the motor centre or at the guard rim); sling length per flight; flight-area size.
