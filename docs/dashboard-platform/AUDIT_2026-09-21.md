## Context

This is a manual audit of the ground station web dashboard, tab by tab, with the drone connected and its physical RC used for arming and disarming. The tasks for the agent are to (1) diagnose and fix the bugs, (2) implement the requested UI and feature changes, and (3) answer the open questions.

**Global pattern:** Most of the dashboard shows yellow "not published" text or "unknown" or "no data", even though the Telemetry Explorer shows about 60 variables streaming correctly with zero loss and a correct sample counter. The likely root cause is a mismatch between the telemetry variable names or slots that the UI panels expect and what the firmware actually publishes, or a missing binding layer. Check this first, because it probably explains many of the individual bugs below.

## 3. Feature and UX Requests

1. **Control tab, parameter commands.** Commands that take values (PID gains, gamma, etc.) should be UI widgets instead of list entries: sliders or numeric inputs that show the current value and the value to set.
2. **Control tab, flag commands.** Flags should be checkboxes or toggles that show the currently active state, so it's always clear what's on.
3. **Estimator tab, mode selector.** Choose between the three estimators (fixed, EMA, EKF).
   - Default to **fixed** (bias estimated at boot and held for the whole flight).
   - Make the **EMA time constant** configurable (increase it to fix the XY pull-back).
   - Show each mode's current estimates and health indicators, with key indicators for all three modes.
4. **Telemetry, subscription UX.** Redesign the subscribe/request-slot flow so it is understandable, explain what "channel" means, and fix the errors.
5. **Path, home and target.**
   - A "Set home = current position" button.
   - A "Set target = current position" button, plus manual entry.
6. **Path, waypoint generator.** Draw or generate random paths on the map, with a configurable spacing between waypoints, and generate the waypoint list immediately.

## 7. Supervisor notes (2026-09-21, read-only GETs)
