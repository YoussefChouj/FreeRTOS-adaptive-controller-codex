# WP-29 research: Yucelen "Lectures on Adaptive Control and Learning" -> firmware and sim lessons

## Question (from the CEO brief)
Map the 29 videos to topics and papers; give published laws, stability conditions, tuning and failure modes; list where
`API/mrac*.c` differs; rank at most 5 WP-27 changes; name sim examples to reproduce in `sim/bench/`.

## Answer (bottom line)
- Lecturer is **Tansel** Yucelen (not "Tolga"), USF, LACIS lab [E1, E2]. Transcripts and Matlab files were not
  reachable, so every table row below is mapped **from the title only**; papers are Yucelen's own work on the same
  topics [E13]. Equations come from open restatements (arXiv/ar5iv, patent), not from the slides.
- Our core law matches published gradient MRAC up to sign convention (u = u_nom + Θ^TΦ, Θ = −Ŵ; `API/controller.c:66`,
  `API/mrac.c:470`). Main gaps: the default reference is a *point* (passthrough), "performance recovery" is a low-pass
  filter on u_ad (L1-style), not Yucelen's frequency-limited reference model, and adaptation is normalized and stacks
  σ + e-mod + LFL leakage.
- WP-27 order: closed-loop/frequency-limited reference model (dense trajectories) > published low-frequency learning >
  barrier (set-theoretic) gain for wind > symbiotic integral term for asymmetric load > derivative-free memory.

## 2. Published laws, conditions, tuning, failure modes
- **Baseline** [E3]: ẋ = Ax + BΛu + BΔ(x); ẋ_r = A_r x_r + B_r c; Ŵ̇ = Γ ω e^T P B; Q + A_r^T P + P A_r = 0.
  Scalability: for c = α c0 use Γ = Γ0/α² [E3]. Failure: high Γ gives high-frequency oscillation [E3, E4].
- **Low-frequency learning** (TAC 2013 as restated in [E3]): Ŵ̇ = Γ ω e^T P B − σ(Ŵ − Ŵ_f), Ŵ_f' = Γ_f(Ŵ − Ŵ_f);
  control uses Ŵ. Theorem not read (TAC PDF is image-only).
- **Performance recovery / frequency-limited error** [E4]: the reference system gets a "mismatch term" with the
  high-frequency part of e; it "yields fast adaptation without incurring high-frequency oscillations". Open equivalent
  with bounds, the closed-loop reference model [E5]: ẋ_m = A_m x_m + b r − L(x − x_m), L = −ℓI;
  ||e||²_L2 ≤ (m||e(0)||² + ||θ̃(0)||²/ρ)/(σ+ℓ), ρ = γ/(σ+ℓ); "the ratio of ℓ and γ is an important design parameter".
  Failure (our inference, not in [E5]): large ℓ lets x_m follow x and hides the ideal response. No source ties
  performance recovery to dense trajectories (title-level link only).
- **To adapt or not to adapt**: no paper with this title found. Closest: L1 control with an output filter equals an LTI
  PI controller [E11]. Title only.
- **Projection** [E6]: f(θ) = (||θ||² − ϑ²)/(2εϑ + ε²); Proj = y − ∇f∇f^T y f/||∇f||² if f > 0 and y^T∇f > 0, else y.
  (θ−θ*)^T(Proj − y) ≤ 0 needs θ* in Ω0; θ stays in Ω1. Component-wise f_i allowed.
- **σ / e-modification** [E7]: θ̇ = −γ[∇L + σG], G = θ (σ) or G = ||e||θ (e-mod); for bounded disturbances. Cost (our
  inference): weights pulled toward 0, steady error under constant load; [E8] adds a fixed-gain term for high leakage.
- **Reference model order/choice**: linear references "can only approximate the desired closed-loop behavior" [E12];
  A_n ≜ A − BK1, B_n ≜ BK2 on the plant state ([E8] eq.3), i.e. same order as the plant.
- **Set-theoretic / barrier** [E9 restating Arabi-Yucelen 2019]: φ = ||e||²_P/(ε² − ||e||²_P), φ_d = ε²/(ε² − ||e||²_P)²
  multiplies the update; ||e(t)||_P < ε(t) for all t. Failure: "barrier transgression" at switches [E9]. A dead-zone
  variant exists (Arabi-Yucelen CEP 89, 2019 [E13]; laws not read). **Event-triggered MRAC**: none found.
- **Neuroadaptive / symbiotic** [E8]: u = u_n + u_f + u_a; Ŵ̇ = β1κ'(e^TPe)σ(x,u_n)e^TPB − β2ασu_f^T − β3Ŵ;
  u_f = −αB_i(x − x0) + αB_i∫(A_n x + B_n r) + ∫u_m (eq.26); κ = ρz near 0 (ρ∈[0,1)), z far out (eq.23).
- **Derivative-free** [E10]: Ŵ(t) = Ω1Ŵ(t−τ) + κ2βỹ^T; Ω1^TΩ1 < κ1I, κ1 < 1/(1+μ), κ2 > 0; example τ = 0.01 s;
  for "sudden changes in weight". Concurrent learning: not in titles, not researched.

## 4. Ranked firmware changes for WP-27 (CPU class PROPOSED, not measured; 200 Hz, STM32F4)
1. **Closed-loop/frequency-limited reference** (types 1, 2): add ℓ(x − x_m) to the x_m update, per-axis ℓ, hold ℓ/γ.
   Why: "the ratio of ℓ and γ is an important design parameter" [E5]; no high-frequency oscillation [E4]. Effect:
   dense trajectory strong, wind medium, load small. CPU O(1), ~3 flops/axis. Test: roll-rate step trains and chirps
   at 3 amplitudes; e RMS and u_ad 20-50 Hz power vs ℓ = 0.
2. **Published low-frequency learning instead of u_ad LPF**: `ENABLE_PERFORMANCE_RECOVERY` 0, σ_lf outside Γ, one
   leakage only. Why: LFL "filters high-frequency content out of the adaptive weight update law" [E3]; output filter
   is PI-like [E11]. Effect: dense trajectories, less lag. CPU ~0. Test: chirp as #1 plus hover; overshoot and lag.
3. **Barrier gain φ_d on s** (variant replacing hard freeze/tanh): s ← φ_d·s, e² clipped at 0.95ε². Why: "||e(t)||_P <
   ε(t)" [E9]. Effect: wind strong, load medium. CPU 1 div + 3 mul/axis. Test: fan gust at hover, ε = e_freeze; max|e| < ε.
4. **Symbiotic integral u_f** with weight-law coupling −β2ασu_f [E8 eq.26, 29] and two-sided bias/cross bounds [E6].
   Why: works with "injudiciously selected adaptive learning parameters" [E8]. Effect: asymmetric load strong, wind
   medium. CPU N+4 flops/axis. Test: 20 g offset payload at an arm tip; steady rate error and Θ_bias vs current.
5. **Derivative-free memory on the bias weight**: Θ(t) = Ω1Θ(t−τ) + κ2·drive, τ = 0.01 s = 2 samples [E10]. Why:
   "sudden changes in weight" [E10]. Effect: payload drop strong. CPU 2-sample buffer. Test: release a hanging mass in hover.
