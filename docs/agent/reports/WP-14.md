## Firmware behaviour
Trip: health 0, `s_ekf_of_inited` and counter cleared (clean re-init next tick), `s_ekf_of_tripped` latches health 0 until the next ARM
edge; mode 2 also falls back to 0, shadow never changes the mode. KF stops ticking (mode != 2, shadow off): `s_ekf_of_inited` cleared.
Active path: `x[1]/x[4]` are body velocity in m/s (OF measurement `(of2_dx_fix - bias) * 0.01` = x[1] + x[2]); `* 100` gives cm/s like
`fb_dx/fb_dy`, same yaw rotation. Not compared: legacy `of2_dx` (raw) vs KF `of2_dx_fix` minus bias.
Slot 3 payload 120 -> 129 B (2 float innov + u8 health; sizes from headers, not the ELF); (7+payload)*100/4 = 3175 -> 3400 B/s, which is
above the brief's ~1600 B/s ceiling (figure not re-derived).
