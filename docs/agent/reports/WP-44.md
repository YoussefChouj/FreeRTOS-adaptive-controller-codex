## Design change from the brief (frame too small for a crc)
The brief's `uint32 name_crc` payload does not fit: a GS frame is `id u8, index u8, value float32`. One frame now
writes one row: CMD **0x2D** (first free id after EXT_POS 0x2C), INDEX = a **permanent row id**, value = float32.
Permanent ids also give stale-firmware safety (an unknown id is refused, never mapped to another variable).
