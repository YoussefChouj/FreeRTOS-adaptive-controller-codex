CEO decisions:
- Items 1-7 of the design as written: reset weights on the injection rising edge, smoothstep alpha with
  `T_up 2.5 s`, alpha also scales the adaptation increment while injecting (1 in shadow), linear `T_dn 0.5 s` on
  injection-off then freeze, alpha 0 + learning off + weights-only reset on the disarm edge or phase LANDED/GROUND_IDLE,
  learning gate `armed && (FLYING || LANDING) && 1.0 s since FLYING` (with fly_ticks hysteresis), shadow uses the same
  gate, injection never ramps in before the gate opens.
- Pass armed and phase as two globals set just before the MRAC call in `TASK/StabilizerTask.c` (~1095), so the
  host stubs stay simple. Leave the simplex fade unchanged.
- Expose `mrac_inj.inj_alpha`, `mrac_inj.learn_gate` as globals and add them plus the simplex fade/tripped flags to
  the slot-0 layout in `ground_station/comm/boot_default_layout.py`. Do not touch `command-panel.js` tonight
  (note the idx 1 -> 10 bug in the report instead).
- Constants as `#define`s in `API/mrac.h` with a one-line WHY each. C for Keil ARMCC V5.06: declarations at block
  top, no VLAs, no C99-only constructs.
