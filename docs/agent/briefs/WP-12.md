# WP-12 brief (CEO -> Manager), 2026-10-01 night. Stream slots that cannot go silent unnoticed.

Base: `night/2026-10-02`. Ground station only: no firmware change, Keil build, flash, 8081, probe or live bridge.

Goal: after an FC reboot every configured stream slot comes back, or the operator is told which one did not, before
arming. Today a lost slot request is never retried and `/api/streams` keeps saying "streaming" (3 of about 10 reboots
on 2026-10-01 lost a slot: active6 slot 0, pidonly7 slot 3, active15 slot 0).
Evidence and fix plan: `docs/agent/reports/2026-10-01-drift-investigation.md`, section `## logging`
(Findings 201-240, Recommendation 242-261, Risks 263-270). Line numbers there are for this branch; re-check them.

CEO decisions (implement these; fix 3 only if 1, 2, 4 and the gate are done and green):
1. Per-slot watchdog in `ground_station/comm/wifi_bridge.py`: `_last_slot_rx[slot]` set in the 0x09-0x0C dispatch;
   `_check_resubscribe` re-requests any configured slot (rate > 0) silent for more than `max(3 s, 5/rate)`, at most
   once per 5 s per slot, even while other slots stream. A silent slot's state becomes `"stale"` (not "streaming")
   and returns to "streaming" on its next frame.
2. `_replay` in `ground_station/service/streams.py` sends one slot at a time, waits up to 500 ms for its schema reply
   or an error (reuse `_await_schemas`), retries up to 3 times, and leaves at least 150 ms between slots
   (the firmware 0x21 mailbox holds one request, `BSP/usart5.c` ~312-339).
3. Merge contiguous address ranges in `_request_stream_schema` (as `subscribe_slot` does) so the slot-0 request
   is well under the 512 B RX buffer. Show the before/after byte count for the boot default layout in a test.
4. StreamLogger (`streams.py` ~230-256): per-slot row counts and status in meta.json at stop; a logged warning plus a
   `slot_faults` list in meta when a configured slot has 0 rows 2 s after start; drop rows where every value is
   empty (the legacy "a" fallback rows).
5. Pre-flight check: `/api/streams/log/start` and the workflow-B arm precheck refuse with "slot N silent" when a
   configured slot's `received` grew by less than 0.8 x rate x 2 over 2 s, after one re-request. Slots at rate 0 are
   exempt. Find the precheck (grep `precheck` / `arm` in `ground_station/service/`), and say where you wired it.
6. Analysis hygiene in `ground_station/analysis/flightlab/loaders/vofa.py`: return an empty frame (not raise) for
   header-only slot CSVs, mask `ano_of.of_alt_cm == 0xFFFFFFFF` (4294967295) to NaN, and mask
   `rpm_dbg_period_cyc[i]` above 5 x its median to NaN. Count masked samples in the returned metadata.
