- Performance recovery (PR): firmware since WP-27 (`API/mrac.h:231-232` kappa_pr, crm_ell; CMD 0x1D idx 4-5), runtime OFF, no campaign.
- Set-theoretic MRAC (a generalised restricted potential scales the adaptation rate with the tracking error; plus the log-barrier
  variant): sim only, `sim/bench/ctrl_p2_yucelen.py:39-140` (MRAC_ST, MRAC_ST_Barrier). Firmware has only `ENABLE_LYAPUNOV_BARRIER 0`
  (`API/mrac.h:79`); find what it does.
- Low-frequency learning with high adaptation gain (filter the weights so a high gamma does not inject high-frequency content): firmware
  has `ENABLE_LOW_FREQ_LEARNING 1` and `sigma_lf` (`API/mrac.h:65,184,279`), but WP-30 found it off at runtime and the high-gain part was
  never configured. Sim: `sim/bench/ctrl_p2_yucelen.py`, `sim/bench/notebook_rpy_mrac.py`.
