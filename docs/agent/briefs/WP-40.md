## Parts
F1. `API/prearm.c/.h`, `PREARM_ROW` table (check id, threshold, unit, enabled; `@` metadata). Checks: estimator ready, battery V at
   rest, RC link, |roll|,|pitch| on the pad, no latched `wfb_safety` trip, task fps from the system monitor. Always compute and
   export `g_prearm_fail_mask` (uint16) and `g_prearm_first_fail`; block arming in `flight_fsm` only for checks with enabled = 1.
   Host test: each check alone, mask bits, enabled = 0 never blocks, RC and GS arm paths.
F2. IWDG (independent watchdog), enable = 0 by default. Refresh only from the system monitor when every critical task
   counter moved this period (`TASK/systemmonitor_task.c`). Set the timeout from a measured worst loop time; you cannot measure it,
   so give the formula and mark the value PROPOSED. At boot always copy RCC_CSR into `g_reset_cause`, clear the flags, export it.
   Host test of the check-in logic.
F3. `g_rtos_budget` (min stack high-water mark + task index, stabilizer CPU %, max loop us), updated at 1 Hz. Add it to
   `API/flight_telemetry.h` as a new `g_tlm` group, and mirror it in `ground_station/platform/telemetry_groups.py`
   (see "How to add a telemetry group").
G. Docs: `docs/firmware-safety.md` (<= 60 lines): each check, its bit, how to enable it, the bench procedure before flight.
