# Feature Parity Matrix — `amosblomqvist/learnharness` vs. `/learn` Harness

## 1. Architectural Mapping Summary

| Subsystem | `amosblomqvist/learnharness` (Reference) | This Repository (`/learn` Harness) | Architectural Rationale |
|---|---|---|---|
| **Teacher / Prober / Practice Engine** | `pi-ai` agent runtime (`src/agent/teacher-agent.ts`) with BYOK API keys / ChatGPT bridge | **Claude Code desktop** driven by `.claude/skills/learn/SKILL.md` | Zero API keys, zero paid external services, native access to repository files and `show_widget`. |
| **Interactive Question & Thinking Cards** | React dock components (`components/question-dock.tsx`, `reading-thinking.tsx`, `practice-dock.tsx`) | HTML widget templates in `.claude/skills/learn/cards/{predict,reading,check,probe,practice}.html` rendered via `show_widget` and submitting via `window.sendPrompt(text)` | Renders natively inside the Claude Code conversation stream and posts structured `[learn] ...` payloads directly into chat. |
| **Plan Map, Proposition Graph, Sessions, Search, Practice & Jobs UI** | Electron + Next.js app (`app/**`, `components/**`) | Local zero-build web app (`tools/learn/viewer/{index.html,app.js,style.css}`) served by `python tools/learn/learn.py serve --port 8770` and launched in Claude Code desktop's browser pane (`learn-viewer` in `.claude/launch.json`) | Pure Python stdlib HTTP server + responsive dark-mode HTML/JS viewer with 3 s live polling and zero npm build overhead. |
| **Persistent Data Store & Graph Scripts** | `skills/learnharness/references/data-format.md` + `scripts/{_data,graph,sessions}.py` | Identical JSON/JSONL layout under `docs/learning/harness/data/` + vendored `tools/learn/vendor/{_data,graph,sessions}.py` + extended CLI in `tools/learn/learn.py` (`tools/learn/API.md`) | 100% backward-compatible on-disk format verified against `golden-data` fixtures. |
| **Specialist Subagents (`research`, `pdf`, `visual`, `demo`)** | Background LLM loops (`src/agent/subagents/*.ts`) | Job records (`learn.py job new --kind ...`) + brief templates in `.claude/skills/learn/jobs/{research,pdf,visual,demo}.md` supporting `helper_worker=inline` or `argon` | Respects project subagent governance: lightweight `pdf`/`visual` run inline; heavy `research`/`demo` emit Argon briefs without spawning unauthorized background processes. |
