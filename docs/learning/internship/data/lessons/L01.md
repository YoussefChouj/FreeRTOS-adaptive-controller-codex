# L01 · How a quadrotor flies (四旋翼怎么飞)

**Bottom line:** a quadrotor can only push straight out of its own top. To go anywhere else, it tilts that push, like leaning forward to start walking.

## 1. One motor
A propeller spinning at speed $\omega$ makes thrust $T_i = k\,\omega^2$. Double the speed and you get 4× the thrust: faster spinning moves more air *and* moves it faster.

## 2. Four motors, one direction
Total thrust $T = T_1+T_2+T_3+T_4$, always along the body z-axis (机体 z 轴).

## 3. Hover (悬停)
Hold height when $T = m g$. For 1.5 kg: $1.5 \times 9.81 = 14.7$ N in total, 3.68 N per motor.

## 4. Rotating (total thrust stays the same)
- **Roll (横滚):** left motors up, right motors down → rolls right.
- **Pitch (俯仰):** rear up, front down → nose dips.
- **Yaw (偏航):** two props spin clockwise, two counter-clockwise; each twists the body the other way (反扭矩). Speed up one pair and slow the other → the body turns.

## 5. Tilting to move
Tilt by $\theta$: the thrust splits into a vertical part $T\cos\theta$ and a horizontal part $T\sin\theta$.

- Hold height: $T\cos\theta = mg \Rightarrow T = \dfrac{mg}{\cos\theta}$
- Sideways acceleration: $a = \dfrac{T\sin\theta}{m} = g\tan\theta$ (unit m/s²)
- Check, 1.5 kg at 20°: $T = 15.66$ N (+6.4%), $a = 3.57$ m/s²

## 6. Combining x, y and z (L01R)
The controller picks a **desired acceleration** $\mathbf{a} = (a_x, a_y, a_z)$ and asks: what thrust vector gives it?

$$\mathbf{F} = m\,(a_x,\; a_y,\; a_z + g)$$

- Thrust size: $T = |\mathbf{F}| = m\sqrt{a_x^2 + a_y^2 + (a_z+g)^2}$
- Tilt size: $\tan\theta = \dfrac{\sqrt{a_x^2+a_y^2}}{a_z+g}$
- Tilt direction (which way to lean): $\varphi = \operatorname{atan2}(a_y, a_x)$

The body z-axis is pointed along $\mathbf{F}$; that becomes the attitude setpoint (姿态期望) for the inner loops. Example, 2 kg, $a = (3, 4, 0)$: horizontal 5 m/s², $\theta = 27.0°$, lean $53.1°$ from x, $T = 22.02$ N. Accelerating upward too ($a_z = 2$): $T = 25.65$ N, $\theta = 22.9°$.

## 7. A chain of loops (串级控制)
```
位置环 → 速度环 → 姿态环 → 角速度环 → 混控器 → 电调 → 电机
slow (tens of Hz) ──────────────────────────► fast (hundreds of Hz to 1 kHz)
```
Each inner loop is faster, so the outer loop can treat it as done instantly. 4 motors, 6 degrees of freedom: the drone is **underactuated (欠驱动)**, so it must tilt before it can move sideways.

## 8. Payload step (from the quiz)
A 2.0 kg drone picks up 0.5 kg and the controller isn't told. Thrust is still 19.62 N, weight is now 24.53 N: net 4.9 N down, so it sinks at 1.96 m/s². The vertical loop sees the height error. With P alone it settles **lower** (a steady sag); higher gains shrink the sag but never remove it. The **integral term (积分项)** keeps adding thrust until the error is zero; new hover thrust 24.5 N, so less margin before saturation (饱和).
